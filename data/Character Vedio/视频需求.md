# 桌宠状态视频需求

桌宠动画 = 视频抽帧（`tools/video_frames.py`）。每个状态一个视频，放进本目录后跑一遍管线即接入。
各状态的生成提示词（英文前缀固定镜头/画风 + 每状态后缀）见同目录 `视频生成提示词.md`。

## 状态进度

| 视频 | 对应状态 | 触发时机 | 状态 |
|------|---------|---------|------|
| `闲置.mp4` | 😴 闲置 | 无事件时 | ✅ 已接入 |
| `思考.mp4` | 🤔 思考中 | 用户提交 prompt 后、生成前 | ✅ 已接入 |
| `执行工具.mp4` | 🔧 执行工具 | Agent 调用工具时 | ✅ 已接入 |
| `错误.mp4` | ❌ 出错 | 工具失败 / 被中断 | ✅ 已接入 |
| `成功结束.mp4` | ✅ 完成 | 一轮任务结束 | ✅ 已接入（比耶欢呼） |
| `读.mp4` | 📝 输出中 | 正在流式输出回复 | ✅ 已接入（读书+漂浮文字） |
| `等待审批.mp4` | ✋ 等待审批 + 💬 需确认 | Agent 等用户批准权限或回答问题时 | ✅ 已接入（73帧三段式：道具出现+合掌 → 等待摆动 → 道具消退） |

未制作的状态自动回退：idle 帧序列 + 参数化整体变换（bounce/bob 等），一直可用。

## 拍摄/生成要求（重要，决定抽帧质量）

1. **同一角色**：绿毛衣眼镜 Q 版女孩，正视图，与已有视频形象一致
2. **纯白底**：不要有场景/渐变/阴影
3. **固定镜头**：不要推拉摇移、不要转视角（抽帧后无法对齐，会循环跳变）
4. **角色全身完整**：不顶边、不出画
5. **时长 3–10 秒**，≥24fps，MP4
6. **首尾姿态尽量接近**（利于工具检测循环段；差异大则自动 ping-pong 往返播放，体积翻倍）
7. **关闭水印**（豆包水印会随帧漂移，靠"只保留最大连通域"过滤；压到角色身上就救不回来了）

## 接入（视频放进来后）

```bash
# 例：success
python tools/video_frames.py "data/success.mp4" src/assets/frames/green-anim --name success
```

然后在 `src/lib/renderer.ts` 的 `FRAME_SKINS["green-anim"]` 加一条 `success` 映射（import 精灵表 + 清单各一行），即自动按状态分发。

## 调参提示

- 首帧中立、动作在中段的视频（如执行工具），用 `--start/--end` 秒数裁掉首尾中立段再循环
- 三段式（入场→循环→出场）：`--intro N --outro M`；素材无自然消退段时 `--outro -1` 用入场倒放作出场（tool-use 齿轮即此方案）
- 体积默认已调色板量化（`--colors 256`），不需要可用 `--colors 0` 关闭
- 循环段检测结果不满意时，缩小 `--start/--end` 范围重跑，肉眼验收 `_preview.png`
- 含**漂浮道具**（✓/星星/沙漏等与角色不连通）的无水印素材：加 `--keep 3~5` 保留面积前 N 的连通域（默认 1 会误杀道具；有水印的素材勿用，水印会复活）
